# arr-cli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eine Agenten-CLI im Unterordner `src/cli/`, die headless über die bestehende Electron-Runtime läuft, Daten kompakt als JSON ausgibt und Analyse/Suche/Grab/Pipeline/Automation auslöst.

**Architecture:** Die portable `ARR Ops.exe` (`out/main/index.js`) verzweigt beim Start: erkennt sie CLI-Argumente (`--cli` oder ein bekanntes Verb), läuft sie headless als CLI statt die GUI zu starten. Die CLI baut denselben `IpcState` wie die GUI auf und ruft dieselben Workflow-Helfer (`enqueue*`) und Repository-Methoden auf — keine duplizierte Geschäftslogik. Lang laufende Jobs werden synchron über `JobRunner.waitFor()` abgewartet.

**Tech Stack:** TypeScript (ESM), Electron, better-sqlite3/drizzle, Node `util.parseArgs` (keine neue Dependency), Vitest.

## Global Constraints

- ESM, `"type": "module"` — Importe mit explizitem Pfad, kein CommonJS.
- Keine neue Laufzeit-Dependency; Argument-Parsing über Node-eingebautes `node:util` `parseArgs`.
- Ausgabe: **kompaktes** JSON auf **stdout** (Default kein Whitespace), Logs/Job-Events auf **stderr**. `--pretty` rückt ein. Exit-Code `0` = ok, `1` = Fehler.
- JSON-Hülle stabil: Erfolg `{ ok:true, hint, data, page? }`, Fehler `{ ok:false, hint, error:{ message, code } }`. Jede Antwort enthält genau einen kurzen `hint`-Satz.
- Listen schlank & paginiert: Default-Limit 20, reduzierte Felder per Default, `--full` für alle Felder.
- Bekannte Verben: `library item quota stats activity jobs instances analyze search grab pipeline automation help`.
- Kein `app.setName(...)` in der CLI (Dual-Mode matcht den `userData`-Pfad automatisch). `migrateDatabase(db)` idempotent aufrufen.
- `tsc --noEmit` (`npm run lint`) muss grün bleiben; Tests via `npm test`.

```ts
export type PageInfo = { total: number; shown: number; offset: number };

export type CommandResult =
  | { ok: true; hint: string; data: unknown; page?: PageInfo }
  | { ok: false; hint: string; error: { message: string; code: string } };

export function ok(data: unknown, hint: string, page?: PageInfo): CommandResult {
  return page ? { ok: true, hint, data, page } : { ok: true, hint, data };
}

export function fail(code: string, message: string, hint: string): CommandResult {
  return { ok: false, hint, error: { code, message } };
}

export function paginate<T>(items: T[], offset: number, limit: number): { slice: T[]; page: PageInfo } {
  const safeOffset = Math.max(0, Math.trunc(offset));
  const slice = items.slice(safeOffset, safeOffset + limit);
  return { slice, page: { total: items.length, shown: slice.length, offset: safeOffset } };
}

export function pickFields<T extends object>(row: T, fields: ReadonlyArray<keyof T>): Partial<T> {
  const out: Partial<T> = {};
  for (const field of fields) {
    out[field] = row[field];
  }
  return out;
}

export function render(result: CommandResult, pretty: boolean): string {
  return JSON.stringify(result, null, pretty ? 2 : undefined);
}
```

```ts
import { parseArgs } from "node:util";

export const KNOWN_VERBS = [
  "library",
  "item",
  "quota",
  "stats",
  "activity",
  "jobs",
  "instances",
  "analyze",
  "search",
  "grab",
  "pipeline",
  "automation",
  "help",
] as const;

export type ParsedArgs = {
  verb: string;
  sub?: string;
  rest: string[];
  ids: number[];
  limit?: number;
  offset?: number;
  sample?: number;
  full: boolean;
  pretty: boolean;
  quiet: boolean;
  nonFunOnly: boolean;
};

export function parseIds(value: string | undefined): number[] {
  if (!value) return [];
  return value
    .split(",")
    .map((part) => Number(part.trim()))
    .filter((n) => Number.isInteger(n) && n > 0);
}

function firstPositional(userArgs: string[]): string | undefined {
  return userArgs.find((arg) => !arg.startsWith("-"));
}

export function isCliInvocation(userArgs: string[]): boolean {
  if (userArgs.includes("--cli")) return true;
  const first = firstPositional(userArgs);
  return first != null && (KNOWN_VERBS as readonly string[]).includes(first);
}

function toInt(value: string | undefined): number | undefined {
  if (value == null) return undefined;
  const n = Number(value);
  return Number.isInteger(n) ? n : undefined;
}

export function parseCliArgs(userArgs: string[]): ParsedArgs {
  const { values, positionals } = parseArgs({
    args: userArgs,
    allowPositionals: true,
    options: {
      cli: { type: "boolean" },
      ids: { type: "string" },
      limit: { type: "string" },
      offset: { type: "string" },
      sample: { type: "string" },
      full: { type: "boolean" },
      pretty: { type: "boolean" },
      quiet: { type: "boolean" },
      "non-fun-only": { type: "boolean" },
    },
  });

  return {
    verb: positionals[0] ?? "help",
    sub: positionals[1],
    rest: positionals.slice(2),
    ids: parseIds(values.ids as string | undefined),
    limit: toInt(values.limit as string | undefined),
    offset: toInt(values.offset as string | undefined),
    sample: toInt(values.sample as string | undefined),
    full: Boolean(values.full),
    pretty: Boolean(values.pretty),
    quiet: Boolean(values.quiet),
    nonFunOnly: Boolean(values["non-fun-only"]),
  };
}
```

```ts
import {
  formatActivityRow,
  formatRadarrRowDates,
  formatSonarrRowDates,
  getQuotaSummary,
  type IpcState,
} from "../main/ipc";
import { SonarrClient } from "../main/arr/sonarr-client";
import { RadarrClient } from "../main/arr/radarr-client";
import type { InstanceKind } from "../shared/ipc-contracts";
import type { ParsedArgs } from "./args";
import { fail, ok, paginate, pickFields, type CommandResult } from "./output";

export const DEFAULT_LIMIT = 20;

export const SONARR_LIST_FIELDS = ["arrId", "title", "status", "monitored", "nonFunFiles", "funShare"] as const;
export const RADARR_LIST_FIELDS = ["arrId", "title", "year", "status", "monitored", "nonFunFiles", "funShare"] as const;

export async function runCommand(state: IpcState, args: ParsedArgs): Promise<CommandResult> {
  switch (args.verb) {
    case "library":
      return libraryCommand(state, args);
    case "item":
      return itemCommand(state, args);
    case "quota":
      return ok(getQuotaSummary(state), "Quota-Fenster pro Window-Stunden. 'stats' zeigt historische Aktivität.");
    case "stats":
      return ok(state.repositories.stats.summary(), "Aggregierte Verlaufsdaten. Aktuelle Bibliothek via 'library summary'.");
    case "activity":
      return activityCommand(state, args);
    case "jobs":
      return jobsCommand(state, args);
    case "instances":
      return instancesCommand(state, args);
    case "help":
      return helpCommand();
    default:
      return fail("unknown_command", `Unbekannter Befehl: ${args.verb}`, "Verfügbare Befehle mit 'help' anzeigen.");
  }
}

function libraryCommand(state: IpcState, args: ParsedArgs): CommandResult {
  const limit = args.limit ?? DEFAULT_LIMIT;
  const offset = args.offset ?? 0;

  if (args.sub === "summary") {
    return ok(state.repositories.mediaItems.summary(), "Gesamtüberblick. Einzellisten via 'library sonarr|radarr'.");
  }
  if (args.sub === "sonarr") {
    let rows = state.repositories.mediaItems.listSonarrRows().map(formatSonarrRowDates);
    if (args.nonFunOnly) rows = rows.filter((row) => row.nonFunFiles > 0);
    const { slice, page } = paginate(rows, offset, limit);
    const data = args.full ? slice : slice.map((row) => pickFields(row, SONARR_LIST_FIELDS));
    return ok(data, listHint(page, "library sonarr"), page);
  }
  if (args.sub === "radarr") {
    let rows = state.repositories.mediaItems.listRadarrRows().map(formatRadarrRowDates);
    if (args.nonFunOnly) rows = rows.filter((row) => row.nonFunFiles > 0);
    const { slice, page } = paginate(rows, offset, limit);
    const data = args.full ? slice : slice.map((row) => pickFields(row, RADARR_LIST_FIELDS));
    return ok(data, listHint(page, "library radarr"), page);
  }
  return fail("missing_argument", "library erwartet: summary | sonarr | radarr", "Beispiel: library sonarr --limit 20");
}

function itemCommand(state: IpcState, args: ParsedArgs): CommandResult {
  const kind = args.sub;
  const arrId = Number(args.rest[0]);
  if ((kind !== "series" && kind !== "movie") || !Number.isInteger(arrId) || arrId <= 0) {
    return fail("missing_argument", "item erwartet: series|movie <arrId>", "Beispiel: item series 123 (arrId aus 'library' entnehmen).");
  }
  const details = state.repositories.mediaItems.itemDetails(kind, arrId);
  return ok(details, `Details zu ${kind} ${arrId}: non-FuN-Dateien und gespeicherte Kandidaten.`);
}

function activityCommand(state: IpcState, args: ParsedArgs): CommandResult {
  const limit = args.limit ?? DEFAULT_LIMIT;
  const rows = state.repositories.activityLog.listRecent(limit).map(formatActivityRow);
  return ok(rows, `Letzte ${rows.length} Aktivitäten. Mehr via --limit N.`);
}

function jobsCommand(state: IpcState, args: ParsedArgs): CommandResult {
  if (args.sub === "status") {
    const id = args.rest[0];
    const job = state.jobRunner.listJobs().find((j) => j.id === id);
```

```ts
const STATUS_PRIORITY: Record<JobStatus, number> = {
  failed: 5,
  blocked_by_budget: 4,
  cancelled: 3,
  running: 2,
  queued: 1,
  completed: 0,
};

export function combineStatuses(statuses: JobStatus[]): JobStatus {
  return statuses.reduce<JobStatus>(
    (worst, current) => (STATUS_PRIORITY[current] > STATUS_PRIORITY[worst] ? current : worst),
    "completed",
  );
}

export function jobsToActionData(jobs: Job[]): {
  jobIds: string[];
  status: JobStatus;
  processed: number;
  total: number;
  succeeded: number;
  failed: number;
} {
  return {
    jobIds: jobs.map((j) => j.id),
    status: combineStatuses(jobs.map((j) => j.status)),
    processed: jobs.reduce((n, j) => n + j.progressCurrent, 0),
    total: jobs.reduce((n, j) => n + j.progressTotal, 0),
    succeeded: jobs.reduce((n, j) => n + j.successCount, 0),
    failed: jobs.reduce((n, j) => n + j.failureCount, 0),
  };
}

async function awaitJobs(state: IpcState, jobs: Job[]): Promise<Job[]> {
  for (const job of jobs) {
    await state.jobRunner.waitFor(job.id);
  }
  return jobs.map((job) => state.jobRunner.listJobs().find((j) => j.id === job.id) ?? job);
}

function actionHint(verb: string, data: ReturnType<typeof jobsToActionData>): string {
  if (data.status === "blocked_by_budget") return "Quota erschöpft — 'quota' prüfen und später erneut ausführen.";
  if (data.status === "failed") return `Fehlgeschlagen (${data.failed} Fehler). Details siehe stderr-Logs.`;
  if (data.status === "cancelled") return "Job wurde abgebrochen.";
  switch (verb) {
    case "search":
      return `${data.succeeded} Einträge durchsucht. Gefundene Kandidaten mit 'grab' holen (Treffer via 'library --non-fun-only' bzw. 'item' prüfen).`;
    case "grab":
      return `${data.succeeded} Grabs ausgelöst, ${data.failed} fehlgeschlagen.`;
    case "analyze":
      return `${data.succeeded} Einträge analysiert. Sichten mit 'library summary'.`;
    case "pipeline":
      return `Pipeline fertig: ${data.succeeded} erfolgreich, ${data.failed} fehlgeschlagen.`;
    default:
      return "Aktion abgeschlossen.";
  }
}
```

```ts
import { app, safeStorage } from "electron";
import { join } from "node:path";
import { createAppDatabase } from "../main/db/client";
import { migrateDatabase } from "../main/db/migrations";
import { createRepositories } from "../main/db/repositories";
import { InstanceStore } from "../main/instances/instance-store";
import { createNotificationAdapter } from "../main/notifications";
import { JobRunner } from "../main/scheduler/job-runner";
import { Scheduler } from "../main/scheduler/scheduler";
import { createSecretStore } from "../main/secrets/secret-store";
import type { IpcState } from "../main/ipc";
import { isCliInvocation, parseCliArgs } from "./args";
import { runCommand } from "./commands";
import { fail, render, type CommandResult } from "./output";

export { isCliInvocation };

function emit(result: CommandResult, pretty: boolean): void {
  process.stdout.write(render(result, pretty) + "\n");
}

export async function runCli(userArgs: string[]): Promise<void> {
  const args = parseCliArgs(userArgs);
  try {
    await app.whenReady();
    const userData = app.getPath("userData");
    const db = createAppDatabase(join(userData, "arr-ops.sqlite"));
    db.pragma("busy_timeout = 5000");
    migrateDatabase(db);
    const repositories = createRepositories(db);
    const instanceStore = new InstanceStore(join(userData, "instances.json"), createSecretStore(safeStorage));
    const jobRunner = new JobRunner(createNotificationAdapter(), {
      persistence: repositories.jobs,
      onChange: args.quiet
        ? undefined
        : (change) => {
            if (change.type === "event" && change.event) {
              process.stderr.write(`[${change.event.level}] ${change.event.message}\n`);
            }
          },
    });
    const state: IpcState = { instanceStore, jobRunner, repositories, scheduler: new Scheduler() };

    const result = await runCommand(state, args);
    emit(result, args.pretty);
    app.exit(result.ok ? 0 : 1);
  } catch (error) {
    const message = error instanceof Error ? error.message : String(error);
    emit(fail("internal_error", message, "Unerwarteter Fehler — Details siehe stderr."), args.pretty);
    if (error instanceof Error && error.stack) process.stderr.write(error.stack + "\n");
    app.exit(1);
  }
}
```

````markdown
# arr-cli — Agenten-CLI für ARR Ops

Headless-CLI, die in derselben Electron-Runtime wie die GUI läuft (nötig für den
Zugriff auf die verschlüsselten API-Keys). Gibt **kompaktes JSON auf stdout** aus;
Logs/Job-Events laufen auf **stderr**.

## Aufruf

- Entwicklung (nach `npm run build`): `npm run cli -- <verb> [optionen]`
  oder `electron out/main/index.js --cli <verb> ...`
- Gepackt: `"ARR Ops.exe" --cli <verb> ...`

**Windows-Konsole:** Die .exe ist ein GUI-Programm. Für zuverlässige Ausgabe per
`spawn`/`exec` mit Pipe-Capture lesen oder in eine Datei umleiten (`> out.json`);
auf interaktive Live-Ausgabe im Terminal nicht verlassen.

## Ausgabeformat

Erfolg: `{"ok":true,"hint":"…","data":…,"page":{…}}` (`page` nur bei Listen)
Fehler: `{"ok":false,"hint":"…","error":{"message":"…","code":"…"}}`
Exit-Code: `0` = ok, `1` = Fehler. `hint` ist immer ein kurzer nächster-Schritt-Tipp.

## Befehle

| Befehl | Zweck |
| --- | --- |
| `library summary` | Gesamtüberblick |
| `library sonarr\|radarr [--limit N] [--offset N] [--non-fun-only] [--full]` | Liste (schlank, paginiert) |
| `item series\|movie <arrId>` | Detail eines Eintrags |
| `quota` | Such-/Grab-Quota |
| `stats` | Verlaufsstatistik |
| `activity [--limit N]` | Letzte Aktivitäten |
| `jobs list \| status <id>` | Jobs |
| `instances list \| test sonarr\|radarr` | Instanzen + Erreichbarkeit |
| `analyze sonarr\|radarr\|all [--ids 1,2] [--sample N]` | Analyse |
| `search sonarr\|radarr --ids 1,2,3` | FuN*-Suche |
| `grab sonarr\|radarr --ids 1,2,3` | Kandidaten grabben |
| `pipeline sonarr\|radarr\|all [--ids 1,2]` | Analyse+Suche+Grab |
| `automation list \| run <goalId>` | Automations-Goals |

Globale Flags: `--pretty`, `--quiet`, `--full`, `--limit N`, `--offset N`.

## Beispiel

```bash

```

## Für AI-Agenten

- Ausgabe immer JSON auf stdout; menschliche Logs ausschließlich auf stderr (`--quiet` schaltet sie ab).
- Listen sind absichtlich schlank und paginiert — `--full`/`item` für Details, `--offset`/`--limit` zum Blättern.

- Den `hint` jeder Antwort lesen — er nennt den sinnvollen nächsten Schritt.
````
